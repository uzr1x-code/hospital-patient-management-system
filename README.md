# Hospital Patient Management System

> **First semester team software project** for the Team Software Project module at the **University of Hertfordshire**.

A **Flask-based web application** for managing hospital patients, doctors, and appointments efficiently.

## Features

- **Patient Management:** Add, view, and archive patient records.
- **Doctor Management:** Add and manage doctor profiles and specialties.
- **Appointments:** Schedule and track patient appointments.
- **Authentication:** Admin login system with secure password hashing.
- **Database:** SQLite backend with SQLAlchemy ORM for easy data handling.
- **Web Interface:** Simple and responsive HTML templates for easy navigation.
